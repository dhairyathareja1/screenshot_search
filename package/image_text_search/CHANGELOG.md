## 0.0.1

### Initial Release

- Added `TextExtractor` for OCR text extraction using Google ML Kit.
- Added `KeywordGenerator` for keyword extraction and stop-word filtering.
- Added `ImageIndexer` for indexing images and generating searchable metadata.
- Added `TextMatcher` for text matching and relevance scoring.
- Added `SearchEngine` for searching indexed images and ranking results.
- Added `IndexedImage` model with serialization support (`toMap` / `fromMap`).
- Added `SearchResult` model for storing search matches and scores.
- Added example Flutter application demonstrating package usage.
